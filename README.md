
# Print work schedule

Simple Shiny app to print work schedule from shared .ics files link.

This is mainly aimed at people using the MyPlan app in the Danish public sector.

To run freely on a server, access here (faster): https://agdamsbo.shinyapps.io/Schedule/

To run purely in your brwoser, access here (slower): https://agdamsbo.github.io/PrintSchedule/

## Motivation

The MyPlan app mainly focus on digital implementation and lacking an easy-to-print overview for the fridge. This app offers that printable overview to share with family.
